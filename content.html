【中西泰人研究会】Useless Machineの開発 2026年4月~6月

Arduinoとサーボモーターを用いて、スイッチを押すと機械自身が押し戻す「Useless Machine」を制作しました。単に押し戻すだけでなく、動作から人間らしさや意思を感じられるよう、押し返す速度や蓋の開閉タイミングを変えて複数の振る舞いを試作しました。最終的にはAT42QT1010静電容量式タッチセンサーと銅箔テープを導入し、スイッチ付近に触れている間は待機し、指を離すとすぐに押し返す仕組みを実装しました。MDFの筐体もIllustratorで図面を作成し、レーザーカッターで加工しています。「機械に見張られている」ように感じるインタラクションを目指して調整を重ねました。

【中西泰人研究会】toio・VRを用いたゲームの開発 2026年6月~7月

小型ロボットtoioを用いて、現実世界とデジタルゲームを組み合わせた体験を研究しています。Unityとtoio SDK for Unityで接続、移動、座標・角度取得、スマートフォン操作を検証し、鬼ごっこ、シューティング、スネークゲームを試作しました。その後、Digital Twinによる実機とUnity上のシミュレーションの連携や、複数のtoioマットをまたぐ座標処理を実装しました。さらに、身の回りの物を障害物として配置し、スマートフォンで撮影した情報をステージへ反映する方法を検討しました。最終的にはMeta Quest 3を導入し、VRからは見えない現実の障害物と、現実世界を移動するtoioを組み合わせたゲームへ発展させました。

じいや！巨大ロボで紅茶を注ぎなさい！

ジャンル: VRゲーム

開発期間: 2026年8月末〜9月（1カ月間）

開発体制: Iwaken Lab. のメンバー4人によるチーム制作

担当: Unityエンジニア（ロボットの腕の挙動、つかみ判定、ティーポットの状態に応じたビジュアルの遷移）

使用技術: Unity、C#、IK（逆運動学）、アニメーション制御、enumによる状態管理、Git / GitHub

出展: DIVE INTO XR（NoMaps2026）／2026年9月26日
会場：Deep Tech Core Sapporo（北海道札幌市）

詳しい説明:
執事となって巨大ロボを操作し、お嬢様のお茶会のために小さなティーカップへ紅茶を注ぐVRゲームです。 巨大なロボットで繊細な作業に挑む、スケールのギャップを楽しめる作品です。 所属するIwaken Lab. のメンバーと共同で開発し、Unityエンジニアとして参加しました。

北海道・札幌を舞台に、テクノロジーやエンターテインメント、クリエイティブを通じて新しい価値を生み出すフェスティバル「NoMaps2026」の連携事業として開催された、XR体験イベント「DIVE INTO XR」に出展しました。

技術説明:
ロボットの腕の制御
UnityのIK（逆運動学）を用いて、ロボットの腕の姿勢を計算する処理を実装しました。主に腕の挙動の作成を担当しています。

つかみ判定とアニメーションの連動
ロボットが掴む動作のアニメーションを作成し、プログラムによるつかみ判定と連動させました。腕の見た目の動作と、ゲーム内でオブジェクトを掴む処理を組み合わせています。

ティーポットの状態管理とビジュアルの遷移
enum型でティーポットの状態を管理し、それぞれの状態に対応する見た目を適用する処理を実装しました。状態の変化に合わせてビジュアルを切り替える部分を担当しました。

JELLY SWIPE

ジャンル: ハイパーカジュアルパズル

開発期間: 2日間（素材準備・コード設計などの事前準備期間：約1週間）

開発体制: 個人開発

担当: 企画、Unityプログラミング、ステージ制作、演出、広告動画制作

使用技術: Unity、C#、DOTween、UniTask、Input System、Android（Google Play）、Codex、Figma、Git / GitHub

操作説明: 上下左右にスワイプして、盤面のゼリーをすべて同時に動かす

詳しい説明:
サイバーエージェントのインターン「Casual Game JAM」で、一人で企画から開発まで行い、Google Playで配信したパズルゲームです。 スワイプすると盤面のゼリーがすべて同じ方向へ、壁やほかのゼリーにぶつかるまで滑ります。同じ色のゴールにすべてのゼリーを入れるとクリアです。 ゲームオーバーはなく、失敗してもすぐにリトライできます。ステージは全130面で、進むにつれてゼリーの色が増えていきます。

企画では、App Storeのランキング上位のカジュアルゲームを数多く遊び、操作感や見た目を分析しました。 その結果から、スワイプだけのシンプルな操作、ひと目で何をするか分かる画面、彩度の高いカラフルな配色を軸に決め、Figmaでトンマナも作成しました。 特に「Block Out!」を参考に、ゴールした瞬間のエフェクトや振動、色合いを研究し、遊んでいて気持ちのいい手触りを目指しました。 配信後はMeta広告で広告を出稿しています。

技術説明:
最初に設計を固めました。盤面の状態（BoardState）とゼリーの移動計算（ZellyMoveCalculate）はMonoBehaviourを継承しない純粋なC#クラスにし、GameObjectを増やさずにロジックだけで動くようにしています。 ゼリー・ゴール・ステージはScriptableObjectで管理し、置くゼリーとその位置、置くゴールとその位置を設定するだけでステージを作れるようにしました。

開発ではAI（Codex）を活用しました。事前に決めた設計に沿ってAIに実装させ、タイトル画面などはworktreeを分けて別のAIに並行で開発させることで、短期間で完成度を高めました。 ステージはJSONで作成してScriptableObjectへ変換できるようにし、全130面について解けることと最短手数を自動で検証しています。

最も時間をかけたのは、ゲームの気持ちよさの調整です。ゼリーの移動速度、壁に当たったときに潰れる動き、ゴールでの発光やゼリーがちぎれる演出、それに合わせた振動を、何度も遊びながら調整しました。 メンターの方からのフィードバックも取り入れ、気持ちよくなるまで改善を重ねました。社員の方からは、人気タイトルを分析できていた点や、周りの人を巻き込みながらフィードバックを取り入れて開発を進めていた点を評価していただきました。

フライパン返し

ジャンル: 体感アクション

開発期間: 2日間（企画・アセット準備などの事前準備期間：約1週間）

開発体制: 3人チーム

担当: 企画、Unityプログラミング

使用技術: Unity、C#、Android、Unity Input System（Accelerometer / AttitudeSensor / LinearAccelerationSensor）、Git / GitHub

詳しい説明:
サイバーエージェントのゲームエンジニア向けインターン「プロトスプリントリーグ」で制作した、スマートフォンをフライパンに見立ててパンケーキをひっくり返すゲームです。Android端末のセンサーを利用し、実際にスマートフォンを傾けたり振ったりする動きをゲーム内のフライパン操作に反映しています。

主にスマートフォンの傾き取得、フライパンの操作、パンケーキの物理挙動、飛ぶ方向の補正、回転制御、キャリブレーションを担当しました。

技術説明:
特に苦戦したのは、パンケーキを自然に飛ばしながら、プレイヤーの意図した方向へ返せるようにする調整です。プログラム側で動きを強く制御すると不自然になり、反対に物理挙動だけに任せると意図しない方向へ飛んでしまう問題がありました。

そこで、奥行き方向への不要な移動を抑えながら、回転をプログラム側で制御することで、物理的な動きを残しつつ遊びやすい挙動になるよう調整しました。

Unity Input SystemのAttitudeSensorで端末の傾きを取得し、LinearAccelerationSensorとAccelerometerで振る動きを検出しています。開発中は実装だけでなく、GitHub運用、タスク分割、スケジュール作成、実機ビルド、ゲームの手触り確認にも取り組みました。社員メンターからは、細かな部分まで手触りを逐一確認し、改善を重ねていた点を評価していただきました。

あなたはシロです。

ジャンル: 3Dアクションパズル

開発期間: 2日間

開発体制: 個人制作

担当: 企画、プログラム、モデリング、レベルデザイン、アニメーション

使用技術: Unity、フルスクリーンシェーダー、Git / GitHub（worktree）

操作説明: プレイヤーを操作し、白と黒の状態を切り替えながらステージを進む

詳しい説明:
刑事ドラマなどで使われる「あなたは黒です」という表現から着想を得た、白と黒の状態を切り替えて進むアクションパズルゲームです。 白の状態では警察は反応しませんが、黒の状態になるとプレイヤーを追いかけます。 あえて黒になって警察を誘導し、その動きを利用して仕掛けを突破していきます。

ただし、黒の状態を使うたびに「黒ゲージ」が蓄積し、プレイヤーの見た目も少しずつ黒く変化します。 タイトルのとおり、最終ステージは白の状態でクリアしなければなりません。 1回目は黒の力を多用して進み、2回目には黒になる回数を抑える必要に気づくという、プレイヤーの理解によって攻略方法が変わる二段構成を目指しました。

技術説明:
企画からプログラム、モデリング、レベルデザイン、アニメーションまで、すべての工程を担当しました。 フルスクリーンシェーダーを活用して画面全体の表現を整え、短期間でも統一感のある世界観になるよう工夫しています。 また、Git worktreeで作業を分割し、AIを活用しながら複数の実装を並行して進めることで、2日間という限られた開発期間でも完成まで持っていきました。 制作を通して、シェーダーによる画面表現と、並列開発を効率良く進める方法を学びました。

詳しい説明:
ハッカソンで制作した、ラケットスポーツのような感覚で遊べるVRアクションゲームです。 プレイヤーはフライ返しでソーセージを打ち、次々と迫ってくる野菜を迎え撃ちます。 ソーセージが当たった野菜はソーセージへ変化するため、コミカルな見た目と爽快なアクションを同時に楽しめます。
